# Patrick Jiang — Portfolio Website

This repository contains the source code for Patrick Jiang's personal portfolio website.

## Pages

- Home (`index.html`)
- About (`about.html`)
- Services (`services.html`)
- FAQ (`faq.html`)
- Contact (`contact.html`)

## Run locally

The site is built with static HTML, so you can open `index.html` directly in a browser or serve the directory with any local HTTP server.

The production site is hosted with GitHub Pages using the custom domain configured in `CNAME`.
